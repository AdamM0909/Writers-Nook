Publish a book

Anything you add here appears on the shelf for everyone with the link. Only you can add books.

1. Name your files
Book file:
Cover image (optional, same name):
2. Upload them to GitHub
  1. Tap the button below and sign in to GitHub. Only the repository owner can upload, so nobody else can add books.
  2. Drop in the book (.pdf, .txt or .md) and its cover image, named as shown above.
  3. Press Commit changes and leave it on the main branch.
Open the upload page
3. Wait about a minute

The site rebuilds itself after every upload. Refresh the library and your book is on the shelf.

To remove or replace a book, open the books folder on GitHub and delete the file.
Published books are public to anyone with the link.
